## Матрица

| Компонент | Текущее состояние | Значение для AGID/AAG |
|---|---|---|
| Multilevel GI dysmotility | **есть**: achalasia + colonic disease + small-bowel CIPO/severe dysmotility | поддерживает neuro-GI mechanism, но неспецифично |
| Objective nonmechanical dysmotility | **есть** в ключевых GI исследованиях | усиливает факт motor disorder |
| Peripheral neuropathy | **есть**, задолго до major GI surgery | делает systemic neuro-GI model правдоподобной |
| Tempo | **многолетний хронический** | менее типично для classic subacute AGID/AAG |
| Orthostatic adrenergic failure | **не документирован standardized** | главный пробел |
| Cardiovagal failure | **не документирован standardized** | главный пробел |
| Sudomotor failure | **не документирован standardized** | главный пробел |
| Bladder/pupillary/secretomotor phenotype | **нужно системно собрать** | поможет generalized vs enteric-limited classification |
| Autonomic reflex screen / CASS | **нет в базе** | самый информативный следующий discriminator при compatible symptoms |
| gAChR antibody | **нет валидированного результата в базе** | testing only after phenotype; low titer alone weak |
| Neural/paraneoplastic antibodies | **нет phenotype-linked modern panel** | targeted only if risk phenotype |
| Sjögren pathway | systemic autoimmune testing 2018 не доказало cause; modern neuro-Sjögren pathway не выполнен | relevant especially if sensory ganglionopathy + autonomic failure |
| Objective immunotherapy response | **нет** | no supportive treatment-response evidence |
| Mechanical/postsurgical causes | **есть** for some obstruction episodes | coexist and must not be mislabeled AGID |
| Genetic/mitochondrial alternative | **open and important** | chronic young-onset phenotype makes this major competing branch |

## Current evidence grade

### За immune-autonomic branch

- objective multilevel GI motor disease;
- peripheral neuropathy predates major surgery;
- a unified neuro-GI mechanism is biologically possible.

### Против / uncertainty

- course is very chronic rather than classic subacute;
- generalized autonomic failure has not been objectively demonstrated;
- no phenotype-matched high-value antibody;
- no objective immune-treatment response;
- strong competing genetic/mitochondrial and enteric-neuromuscular hypotheses.

## Рабочая оценка

**AGID/AAG: низкая–средне-низкая текущая доказанность, но meaningful to test objectively.**

Это не означает `immune cause unlikely enough to ignore`; это означает, что следующий шаг должен повышать/понижать probability объективно.

## Что сильнее всего изменит оценку

1. Structured autonomic symptom inventory.
2. Standardized autonomic reflex testing/CASS if symptoms support it.
3. Objective GI motility dataset assembled in one timeline.
4. Expert EDX sensory/autonomic phenotype.
5. Only then targeted antibodies with antigen + assay + titer.
6. Sjögren/PNS-Care branch only if phenotype/serology supports it.

## Stop rule

If systemic autonomic testing is repeatedly normal and no immune/paraneoplastic/Sjögren evidence emerges, while genetics/pathology produces a coherent alternative, AGID branch should be deprioritized rather than repeatedly expanded with broad antibody panels.
