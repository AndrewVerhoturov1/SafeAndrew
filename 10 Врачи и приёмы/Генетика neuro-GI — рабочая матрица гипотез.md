## 1. Исходный phenotype для генетика

Документированы:

- chronic peripheral neuropathy с 2017;
- ранний преимущественно sensory component;
- sensory ataxia/deep sensory loss;
- posterior-column spinal abnormalities 2026;
- achalasia;
- severe colonic dysmotility/megadolichocolon → colectomy;
- later severe small-bowel dysmotility/CIPO phenotype;
- objective very slow small-bowel transit without fixed mechanical obstruction in key evaluations;
- coexistence of postsurgical/mechanical complications, which must be separated from primary motor disease.

## 2. Candidate matrix

| Ветка | Что совпадает | Что уменьшает fit / неизвестно | Что реально проверяет | Приоритет |
|---|---|---|---|---|
| **Broad inherited neuro-GI / mitochondrial** | young neuropathy + multilevel GI dysmotility | no molecular result yet | broad NGS/exome/genome with explicit CNV/SV/mitochondrial coverage | **высокий как testing strategy** |
| **Classic TYMP-MNGIE** | severe GI dysmotility + neuropathy + relatively young onset | MRI brain 19.09.2024: no focal/demyelinating abnormalities, no diffuse leukoencephalopathy described; ptosis/ophthalmoplegia not documented in current index; cachexia phenotype needs reconstruction | TYMP + plasma thymidine/deoxyuridine and/or TP activity if specialist thinks phenotype fits | **lower than generic MNGIE-like** |
| **POLG MNGIE-like** | neuropathy can be sensory/ganglionopathic/axonal; GI dysmotility; leukoencephalopathy not required | no documented POLG-specific multisystem constellation; genetics not done | broad mitochondrial nuclear testing / POLG analysis with clinical correlation | **meaningful branch** |
| **RRM2B MNGIE-like** | GI dysmotility + neuropathy possible | very rare; ptosis/ophthalmoplegia/cachexia not established | broad mitochondrial panel/exome/genome including RRM2B | **lower individual gene, include in broad test** |
| **RFC1 expansion** | sensory neuropathy/ataxia + posterior-column involvement compatible | neuropathy documented before age 30; classic RFC1 usually later onset; severe CIPO not core feature | explicit RFC1 repeat-expansion assay | **targeted add-on if sensory phenotype confirmed** |
| **ACTG2 / visceral smooth-muscle disease** | severe CIPO/megacolon phenotype | does not naturally explain generalized peripheral neuropathy; bladder/megacystis phenotype not yet documented; full-thickness myopathy not proven | ACTG2 + broad smooth-muscle genes if pathology/urinary phenotype supports | **important GI branch, weak single-diagnosis unifier** |
| **Other smooth-muscle genes** | CIPO can occur with MYH11/FLNA/MYLK/RAD21/MYL9/LMOD1 | many published phenotypes pediatric and bladder-associated | broad smooth-muscle coverage | **pathology/phenotype dependent** |
| **Enteric neuropathy genes / other mitochondrial/systemic genes** | can connect enteric and peripheral nervous systems | broad/heterogeneous; no pathology yet | broad neurogastrointestinal genetics + pathology-guided reanalysis | **meaningful category** |
| **Dual diagnosis** | strong independent neuropathy + strong independent CIPO; some candidates explain only one organ system | cannot be confirmed until broad testing/pathology | interpret every genetic finding by which phenotype it explains | **must remain allowed** |

## 3. Classic TYMP-MNGIE — current discriminator

Primary MRI document:

[[02 Первичные документы/2024/2024-09-19 МРТ головного мозга №69206-24]]

describes brain without focal changes and does not describe diffuse white-matter leukoencephalopathy.

Because classic TYMP-MNGIE is strongly associated with leukoencephalopathy, this **reduces fit of classic TYMP-MNGIE**.

It does **not** exclude POLG/RRM2B MNGIE-like disease or other mitochondrial disorders.

## 4. What a genetics report must not say

Insufficient:

- `TTR negative → inherited neuropathy excluded`;
- `exome negative → RFC1 excluded`;
- `ACTG2 VUS → explains everything`;
- `MNGIE panel negative → mitochondrial disease excluded` without assay description.

## 5. Minimum technology audit

For every genetic test record:

| Technology | Covered? |
|---|---|
| SNV/indels | yes/no/unknown |
| exon-level CNV | yes/no/unknown |
| structural variants | yes/no/unknown |
| RFC1 repeat expansion | yes/no/unknown |
| mtDNA sequencing/heteroplasmy | yes/no/unknown |
| nuclear mitochondrial genes | yes/no/unknown |
| reanalysis policy | yes/no |
| VUS/segregation options | yes/no |

## 6. What would most narrow the branch before testing

1. Expert EDX phenotype.
2. Bladder/urinary smooth-muscle history.
3. Ophthalmologic exam for ptosis/ophthalmoplegia.
4. Weight/cachexia trajectory before major surgery.
5. Family history.
6. Full-thickness bowel pathology re-review if tissue exists.
7. Exact old genetic test method/coverage, including TTR report details.

## 7. Success criterion

Genetics is considered informative only when the report answers:

- what molecular mechanisms were tested;
- what was not tested;
- whether finding explains neuro, GI, or both;
- whether confirmatory biochemical/segregation/pathology evidence is required.
