# Import Medical Documents Implementation Plan

> **For agentic workers:** This plan records the completed first import of the user's supplied medical records.

**Goal:** Перенести предоставленные медицинские документы в структуру Obsidian и связать их с хронологией и медицинскими направлениями.

**Architecture:** Первичные расшифровки хранятся по годам в `02 Первичные документы/`. Производные страницы содержат краткие утверждения только со ссылками на конкретные источники и разделы.

**Tech Stack:** Markdown, Obsidian wiki-links, YAML properties, GitHub.

## Global Constraints

- Первичные документы не смешивать с гипотезами.
- Исторические назначения не считать действующими.
- Различия расшифровок сохранять явно.
- Для межпапочных ссылок использовать путь от корня хранилища.
- `main` не изменять до решения пользователя.
