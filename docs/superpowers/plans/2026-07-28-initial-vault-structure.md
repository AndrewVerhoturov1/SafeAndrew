# Initial SafeAndrew Vault Structure Implementation Plan

> **For agentic workers:** Execute this plan task-by-task and verify every created file and link.

**Goal:** Создать первоначальную структуру хранилища Obsidian и правила работы агентов.

**Architecture:** Главная страница связывает индексы разделов. Первичные документы, медицинские сводки, направления, гипотезы и ежедневные записи разделены. Машиночитаемые правила находятся в `system/`, а инструкции агентов — в `.agents/`.

**Tech Stack:** Markdown, Obsidian wiki-links, YAML properties, GitHub.

## Global Constraints

- Видимые названия — на русском.
- Постоянные `id` — на латинице.
- Не переносить медицинские документы в рамках этой задачи.
- Не изменять `main` во время подготовки.
