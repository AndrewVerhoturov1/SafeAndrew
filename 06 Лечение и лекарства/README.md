## Неврологические назначения 2018 года

В выписке указаны:

- тиоктовая кислота 600 мг утром три месяца;
- пентоксифиллин 100 мг трижды в день один месяц;
- витаминный комплекс один месяц;
- Магнерот по указанной в выписке ступенчатой схеме;
- фолиевая кислота 1 мг в день два месяца;
- сертралин 50 мг вечером не менее шести месяцев;
- лечебная физкультура.

Источник: [[02 Первичные документы/2018/2018-12-04 Выписка неврология №40850#Рекомендации|рекомендации 2018]].

## Неврологические назначения 2026 года

В выписке указаны:

- витамин B12 — 1000 мкг внутримышечно ежедневно две недели, затем 500 мкг трижды в неделю два месяца;
- фолиевая кислота 5 мг в сутки один месяц;
- тиоктовая кислота по ступенчатой схеме;
- витамин E;
- белковая диета;
- наблюдение у невролога, гастроэнтеролога, хирурга и психиатра или психотерапевта.

Источник: [[02 Первичные документы/2026/2026-01-27 Выписной эпикриз неврология №229-С-2026#Рекомендации при выписке|рекомендации 2026]].
