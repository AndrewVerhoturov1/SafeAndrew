# Skill: build-scientific-library-document

## Purpose

Use this skill when creating or updating scientific library documents.

## Required reading

- `AGENTS.md`
- `07 Научная база/README.md`
- `system/scientific-library-workflow.md`

## Process

### 1. Define purpose

Identify:
- clinical question;
- evidence package;
- whether Level 1, Level 2, or both are needed.

### 2. Validate source

Record:
- title;
- organization/authors;
- year;
- version;
- DOI/PMID/URL when available;
- update or replacement status.

### 3. Build Level 1

Create source documents that:
- preserve context;
- retain clinical logic;
- include limitations;
- avoid patient-specific conclusions.

Do not create a short opinionated summary.

### 4. Build Level 2

Create topic documents that:
- answer one clinical question;
- synthesize multiple sources;
- link claims to Level 1;
- mark uncertainty.

### 5. Final checks

Confirm:
- source and topic levels are separated;
- references are traceable;
- no unsupported medical conclusions are added;
- limitations are documented.
