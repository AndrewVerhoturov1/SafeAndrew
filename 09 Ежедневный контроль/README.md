# Ежедневный контроль

## Быстрая голосовая запись питания и стомы

Для частой диктовки в ChatGPT используется отдельный append-only журнал:

[[09 Ежедневный контроль/Питание и стома/README|Питание и стома — журнал]]

Канонический принцип для обычного сообщения:

```text
пользователь диктует факт
→ модель сама определяет дату/время
→ записывает в 09 Ежедневный контроль/Питание и стома/YYYY-MM-DD.md
→ commit в main
→ коротко подтверждает
→ останавливается
```

Модель не должна автоматически анализировать питание, работу стомы или медицинское значение записи.

Системный контракт:

[[system/voice-food-stoma-capture-contract|Контракт голосовой записи питания и стомы]]

## Возможные показатели общего ежедневного контроля

- лекарства и уколы;
- питьё и признаки обезвоживания;
- питание;
- состояние и объём отделяемого по стоме;
- боли и вздутие;
- онемение, слабость и устойчивость;
- вес, давление и пульс;
- сон и настроение;
- новые необычные симптомы.
