# Ежедневный контроль

## Возможные показатели

- лекарства и уколы;
- питьё и признаки обезвоживания;
- питание;
- состояние и объём отделяемого по стоме;
- боли и вздутие;
- онемение, слабость и устойчивость;
- вес, давление и пульс;
- сон и настроение;
- новые необычные симптомы.
