## Главный вывод

Безопасная диагностика CIDP требует одновременно избегать двух противоположных ошибок:

- **overdiagnosis** — любой slowing/block называют CIDP;
- **underdiagnosis** — настоящий приобретённый демиелинизирующий процесс пропускают из-за неполного NCS, атипичного фенотипа или недостаточного клинического осмотра.

## 1. Четыре уровня проверки

### Уровень 1 — клиника

Зафиксировать:

- длительность и динамику;
- proximal vs distal weakness;
- symmetry/asymmetry;
- sensory involvement;
- reflexes;
- соответствие typical или variant phenotype.

### Уровень 2 — формальный EAN/PNS

Для каждого нерва:

- параметр;
- значение;
- лабораторный LLN/ULN;
- критерий выполнен / нет / неинтерпретируем;
- число независимых нервов.

### Уровень 3 — качество и механизм

Проверить:

- distal CMAP;
- temperature;
- waveforms;
- latency markers;
- compressible sites;
- amplitude-dependent slowing;
- block/temporal dispersion;
- axonal denervation;
- nodal/hereditary alternatives.

### Уровень 4 — mimics/supportive data

Проверять по фенотипу:

- paraprotein / anti-MAG;
- hereditary neuropathy;
- ATTRv;
- MMN;
- nodopathy;
- GBS/acute-onset patterns;
- другие systemic neuropathies.

Supportive tests не заменяют предыдущие три уровня.

## 2. Красные флаги overdiagnosis

- NCS не выполняет формальные критерии;
- диагноз держится на mild/moderate slowing;
- CMAP очень низкий, но slowing трактуется без оговорки;
- ключевая аномалия только в месте компрессии;
- вывод основан главным образом на fibular→EDB <1 мВ;
- повышенный CSF protein используется как главный аргумент;
- treatment response субъективен;
- нет proximal weakness для типичного фенотипа;
- не исследованы альтернативные причины.

## 3. Красные флаги underdiagnosis

- proximal weakness не проверялась/не документировалась;
- atypical phenotype автоматически отвергается;
- неполный односторонний NCS используется как окончательное исключение;
- настоящие demyelinating features есть, но не распознаны;
- исследование не расширено при высокой клинической вероятности.

## 4. Low-CMAP правило

CMAP <1 мВ требует отдельной маркировки:

`интерпретация slowing ограничена`.

Нужно по возможности:

- проверить waveform;
- оценить marker placement;
- искать данные других нервов;
- использовать более проксимальную мышцу, если это методически оправдано;
- не делать вывод о генерализованной демиелинизации из одного low-amplitude нерва.

## 5. Почему выполнение EDX criteria не завершает диагноз

Broers 2021 показывает, что часть overdiagnosed пациентов формально выполняла EFNS/PNS criteria, но имела другую болезнь.

Значит, после положительных критериев обязательно остаётся вопрос:

> какая болезнь объясняет демиелинизирующий/псевдодемиелинизирующий паттерн?

## 6. Почему невыполнение EDX criteria тоже не всегда завершает вопрос

van Doorn 2026 показывает, что limited NCS снижает чувствительность.

Поэтому при высокой клинической вероятности нужно оценить полноту исследования, а не только поставить `criteria negative`.

## 7. Рекомендуемый формат итогового заключения агента

Не:

`CIDP есть / нет`.

А:

1. **Phenotype:** ...
2. **EAN/PNS status:** ...
3. **Data quality:** ...
4. **Low-CMAP / technical limitations:** ...
5. **Mechanistic interpretation:** ...
6. **Main mimics:** ...
7. **Supportive data:** ...
8. **Diagnostic confidence:** высокая / средняя / низкая / недостаточно данных.
9. **Что изменит решение:** конкретный следующий тест/экспертный шаг.

## 8. Статус

Первая зрелая версия диагностической рамки. Следующий слой — стандарты AANEM по качеству выполнения/отчётности и reference values.

## Дополнение У1 от 21.10.2026 — порог категорий и недостаточный объём NCS

**van Doorn 2026**, DOI `10.1111/ene.70726`, в исследовании **339 CIDP + 339 подобранных контролей** обнаружили по индексированным разделам издателя и Table 5:

| Объём теста | CIDP + possible CIDP (чувствительность / специфичность) | Только CIDP (чувствительность / специфичность) |
|---|---|---|
| Полная ЭНМГ/NCS | **94% / 66%** | **83% / 86%** |
| Ограниченная односторонняя NCS | **78% / 82%** | **51% / 97%** |

**Не объединять** `possible` с строгой категорией для заявления более высокой точности. Ретроспективная диагностическая референсная классификация использовала часть прежних критериев и оценку ответа на лечение; возможен **incorporation bias**. Контроли не охватывают все демиелинизирующие «мимики». Показатели не универсальны для общей популяции или иной лаборатории. Источник по приёмке B: **индексированные Table 5/§3.4, Wiley 403 при прямом полном открытии; supplementary не прочитан**.

**Gallo 2026** проверяет отдельные definitions CB/TD в другой специализированной выборке, **не общий диагноз CIDP**. Число нервов, кривых или статей не складывается как количество независимых пациентов; возможные пересечения не доказаны.

Отсутствие формального критерия из-за недостающих latencies/LLN/waveforms должно иметь статус **«не оценим»**, а не «CIDP исключён».
