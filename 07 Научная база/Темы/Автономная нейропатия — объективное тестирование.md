## Главный принцип

Symptoms ≠ objective autonomic failure.

Standardized autonomic reflex testing позволяет количественно определить domains и severity.

## Core domains

| Domain | Типичные тесты | Что показывает |
|---|---|---|
| Adrenergic | orthostatic challenge, Valsalva BP | sympathetic vasomotor function |
| Cardiovagal | deep breathing, Valsalva HR | parasympathetic cardiac control |
| Sudomotor | QSART/validated sweat testing | postganglionic sudomotor function |
| Orthostatic | continuous BP + HR upright | OH/POTS-like physiology |

## CASS

CASS полезен для generalized autonomic failure, если исходная battery выполнена валидно.

## GI limitation

Autonomic lab не заменяет GI motility testing.

Возможны:

- generalized autonomic neuropathy + GI dysmotility;
- predominantly/isolated enteric dysmotility при normal systemic testing.

## Repeat testing

Repeat может использоваться для objective follow-up, если:

- baseline abnormal;
- technical protocol comparable;
- результат реально влияет на management.

## Skin biopsy

Skin biopsy может поддерживать small-fiber pathology, но finding не равен autonomic etiology и должен коррелировать с physiology.

## Правило SafeAndrew

Любая фраза `вегетативная нейропатия` должна сопровождаться:

- symptoms/domains;
- objective tests;
- severity;
- distribution;
- etiologic confidence.
