## Краткий вывод

Для экспертного исследования недостаточно `правильного аппарата` или длинного списка нервов.

Нужны **два независимых качества**:

1. исследование должно быть правильно спроектировано и адаптировано врачом в реальном времени;
2. после исследования должен остаться отчёт, достаточный для независимой проверки и сравнения.

## 1. Качество процесса

Минимальные признаки:

- EDX-trained physician;
- in-person history + examination;
- clinical differential до выбора protocol;
- real-time NCS interpretation;
- возможность менять nerve/segment/muscle;
- needle EMG интегрируется по клинической задаче.

## 2. Качество документации

Должны быть доступны:

- nerves/muscles/side;
- stimulation/recording sites;
- distances;
- reference values;
- temperature;
- latencies;
- amplitudes;
- conduction velocities by segment;
- F-wave minimum latency;
- needle EMG details;
- technical limitations;
- interval comparison, если он валиден.

## 3. Оригинальные waveforms

AANEM не требует их обязательного включения в обычный report, но рекомендует retention.

Для экспертного пересмотра SafeAndrew они имеют особую ценность, потому что позволяют проверить:

- latency onset;
- waveform morphology;
- temporal dispersion;
- true vs apparent conduction block;
- artifact/co-stimulation;
- качество очень малых ответов.

## 4. Критерий пригодности старого исследования для сравнения

Рабочая оценка SafeAndrew:

- **A:** полный report + референсы + temperature + waveforms;
- **B:** достаточная numeric table + референсы, но нет части raw data;
- **C:** неполная numeric table / неясная техника;
- **D:** только заключение.

Это внутренняя рабочая шкала, не классификация AANEM.

## 5. Требование к новому экспертному исследованию

Если повтор понадобится, запрос должен быть сформулирован не как `повторить ЭНМГ`, а как:

> провести neuromuscular/EDX evaluation с осмотром, адаптивным NCS + needle EMG, формальной проверкой demyelinating criteria, sensory-neuronopathy pattern и сравнением с предыдущими данными.

## 6. Температура как отдельный контроль качества

AANEM 2026 подчёркивает, что конечность может остывать **во время** исследования, поэтому температуру недостаточно проверить один раз.

Рабочая таблица источников:

| Источник | Upper | Lower |
|---|---|---|
| EAN/PNS 2021 | ладонь ≥33°C | наружная лодыжка ≥30°C |
| AANEM Reporting 2024 | кисть 32–36°C | стопа 30–36°C |
| AANEM Temperature 2026 | generally >32°C | generally >31°C |

Правило SafeAndrew: сохранять фактическую температуру и laboratory protocol; не выбирать задним числом наиболее удобный threshold.

Если холод выявлен, предпочтительно rewarm, а не использовать математическую correction formula.

## 7. Reference values должны быть методически совместимы

Dillingham 2016 добавляет отдельную проверку качества нормы.

Перед использованием LLN/ULN будущий агент должен установить:

- откуда взята норма;
- совпадают ли stimulation/recording sites и distances;
- совпадают ли filter/settings;
- как контролировалась temperature;
- учтены ли age/height/BMI;
- как статистически получен cut-off;
- переносима ли эта норма на конкретную лабораторию.

Правило SafeAndrew: локальная валидированная норма для конкретной методики имеет приоритет над произвольной общей цифрой.
