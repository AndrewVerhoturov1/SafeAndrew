## Главный вывод

`Норма` в NCS — это не универсальная константа.

Она связана с:

- конкретной техникой;
- расстоянием;
- recording/stimulation sites;
- filters;
- temperature;
- age/height/BMI;
- статистическим методом получения LLN/ULN.

## 1. Иерархия reference values SafeAndrew

Приоритет:

1. **валидированные нормы конкретной лаборатории для фактически использованной техники**;
2. **высококачественный внешний reference source с достаточно совпадающей техникой**;
3. общие справочные значения только как ориентир.

Если источник нормы неизвестен, confidence результата снижается.

## 2. Что агент обязан хранить рядом с числом

Не:

`CV = 38 м/с, снижена`.

А минимум:

`CV = 38 м/с; nerve/segment = ...; distance = ...; temperature = ...; lab LLN = ...; reference source = ...`.

Если поля неизвестны — писать `неизвестно`.

## 3. Межлабораторная динамика

Изменение между годами считается надёжным только если:

- исследован тот же нерв/segment;
- recording muscle/site совпадает;
- distance сопоставима;
- temperature сопоставима;
- technique/filters не создают существенного systematic difference;
- response достаточно велик и waveform интерпретируем;
- reference frameworks понятны.

Если нет — сравнивать можно качественно, но не делать вид, что 2–5 m/s точно отражают biological progression.

## 4. Age/height/BMI

Chen 2016 показывает заметные эффекты:

- fibular/tibial amplitude и velocity меняются с age/height;
- median/ulnar sensory amplitude — с age/BMI;
- median motor — часть параметров зависит от age/gender.

Следовательно, возрастные/антропометрические covariates нельзя игнорировать при пограничных значениях.

## 5. Nerve-specific exceptions

### Fibular

Normal segmental variation around fibular head существует; локальная разница не равна автоматически acquired demyelination.

### Tibial

Proximal amplitude drop может быть очень большим у normal subjects при конкретной записи AH; generic conduction-block logic здесь особенно опасна.

### Sensory

Низкоамплитудные SNAP сильно чувствительны к технике/шуму; отсутствие superficial fibular high-quality normative study в NDTF должно оставаться явным limitation.

## 7. Что нельзя делать

- подставлять одну таблицу Chen ко всем старым исследованиям;
- объявлять любое значение чуть ниже external LLN патологическим без техники;
- считать отсутствие reference interval в старом протоколе эквивалентом нормальной современной методики;
- сравнивать проценты амплитудного drop разных nerves одинаково;
- скрывать отсутствие подходящей нормативной базы.

## 8. Практическая ценность

Этот документ защищает экспертный пересмотр от **ложной точности**.

Наша цель — не пересчитать старые протоколы под одну новую норму, а определить:

- какие параметры действительно сопоставимы;
- где можно уверенно сказать `изменилось`;
- где остается только `вероятно/неопределённо`;
- где нужен новый стандартизированный baseline.
