## 4. Что сделали авторы

NDTF искала опубликованные reference studies для 11 routinely tested sensory/motor nerves за 1990–2012 годы и оценивала их по методическим критериям Dillingham/NDTF.

- найдено >7 500 статей;
- 401 имели >100 normal subjects;
- 83 прошли на detailed review;
- только по 10 из 11 нервов нашлось по одному основному исследованию, удовлетворявшему всем критериям;
- для superficial fibular sensory nerve подходящего primary study не нашли.

## 5. Стандартизированная техника

В выбранных исследованиях авторы описывают:

- electrode placement;
- stimulation sites;
- fixed distances;
- display settings;
- filters.

Температуру поддерживали:

- >32°C для upper limb;
- >31°C для lower limb.

В sensory studies использовались filters 20 Hz–2 kHz; в motor studies 2–3 Hz–10 kHz.

Эти детали являются частью нормы: цифра cut-off не должна отделяться от техники, при которой она получена.

## 6. Основные выбранные sensory reference values

Таблица 3 публикует lower amplitude limits (обычно 3rd percentile) и upper latency limits (97th percentile) для стандартизированных техник.

Примеры:

- superficial radial sensory, antidromic 10 cm: amplitude LL 7 µV onset-to-peak / 11 µV peak-to-peak; onset latency UL 2.2 ms; peak latency 2.8 ms;
- median sensory, digit 2, wrist 14 cm: amplitude LL 11/13 µV; onset latency UL 3.3 ms; peak 4.0 ms;
- ulnar sensory, digit 5, 14 cm: amplitude LL 10/9 µV; onset latency UL 3.1 ms; peak 4.0 ms;
- sural sensory, antidromic 14 cm: amplitude LL 4/4 µV; onset latency UL 3.6 ms; peak 4.5 ms.

Median/ulnar sensory amplitudes менялись с age и BMI; subgroup values опубликованы отдельно.

## 7. Основные выбранные motor reference values

Для конкретных описанных техник Table 4 приводит:

- median motor → APB, 8 cm: distal amplitude LL 4.1 mV, CV LL 49 m/s, distal latency UL 4.5 ms;
- ulnar motor → ADM, 8 cm: distal amplitude LL 7.9 mV, CV LL 52 m/s below elbow / 43 m/s across elbow / 50 m/s above elbow, distal latency UL 3.7 ms;
- fibular motor → EDB, 8 cm: distal amplitude LL 1.3 mV, ankle-to-below-fibular-head CV LL 38 m/s, distal latency UL 6.5 ms;
- tibial motor → abductor hallucis, 8 cm: distal amplitude LL 4.4 mV, CV LL 39 m/s, distal latency UL 6.1 ms.

Возраст/рост/пол влияют на часть параметров; полные subgroup values остаются в оригинальных Tables 3–5.

## 8. Segmental differences, которые нельзя игнорировать

### Fibular nerve

В selected study:

- normal drop CV lower leg → across knee: до 6 m/s или 12%;
- normal amplitude drop below → above fibular head: до 25%;
- age существенно влияет на amplitude, height — на CV.

### Tibial nerve

В selected study normal amplitude drop ankle → knee достигал **10.3 mV / 71%**.

Авторы специально предупреждают, что такой большой proximal amplitude drop у нормальных субъектов может быть ошибочно принят за conduction block; вероятный механизм — temporal dispersion и phase cancellation при записи от сложной дистальной мышечной области.

Это сильный пример того, почему generic percentage-drop rule нельзя применять без nerve/muscle-specific reference.

## 9. Sural response и отсутствие ответа

В selected sural study:

- двусторонне отсутствовал ответ у 4 человек;
- односторонне отсутствовал ещё у 4;
- обе стороны были регистрируемы у 97% normal subjects.

То есть `absent sural SNAP` не должен оцениваться без age/technique/context, хотя в большинстве здоровых взрослых ответ регистрировался.

## 10. Ограничения

- почти все окончательно выбранные reference studies происходили из одной research group / одного регионального healthy adult population и одной EDx laboratory;
- нужна multicenter/geographically diverse validation;
- NDTF не нашла подходящего primary reference study для superficial fibular sensory nerve;
- late responses (F-waves/H-reflexes) не были целью этого проекта;
- pediatric populations не рассматривались;
- reference values корректны только при воспроизведении техники.

## 11. Почему источник добавлен

Он даёт агенту **не универсальные нормы**, а проверенные reference candidates, связанные с точными методиками.

Правильное использование:
