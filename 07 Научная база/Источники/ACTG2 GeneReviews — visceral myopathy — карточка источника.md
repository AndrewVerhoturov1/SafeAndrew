# ACTG2 Visceral Myopathy GeneReviews — карточка источника

## Паспорт

- **GeneReviews:** NBK299311
- **Last update:** 2021-05-06
- **PMID:** 26072522

## Phenotype

ACTG2 visceral myopathy is a smooth-muscle disorder affecting GI tract and bladder.

Spectrum ranges from severe neonatal megacystis-microcolon intestinal hypoperistalsis syndrome to later/intermittent chronic intestinal pseudo-obstruction and bladder dysfunction.

## Inheritance

Usually autosomal dominant; many affected individuals have **de novo** variants, so negative family history does not exclude ACTG2.

## Critical boundary for SafeAndrew

ACTG2 can strongly explain a **visceral smooth-muscle/CIPO phenotype**, but it is not a canonical explanation for generalized peripheral neuropathy.

If ACTG2 were found, agent must still ask whether neurological disease is part of the same diagnosis or a second process.
