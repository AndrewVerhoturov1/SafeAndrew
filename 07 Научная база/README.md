# Научная база

Здесь хранятся клинические рекомендации, систематические обзоры, исследования и их разбор применительно к личной медицинской картине.

## Использовано в полном анализе первичных документов

- [[07 Научная база/Опорные источники для анализа 2026-08-11|Опорные источники для анализа 11.08.2026]]

В разбор включены современные рекомендации и обзоры по:

- диагностике хронической полинейропатии;
- критериям CIDP;
- дефициту B12;
- дефициту меди и заднеканатиковой миелопатии;
- диагностике нейроборрелиоза;
- интерпретации серологии ВЭБ;
- железодефицитной анемии;
- экзокринной недостаточности поджелудочной железы;
- хронической кишечной псевдообструкции.

## Правило применения литературы

Современная литература используется **после** извлечения фактов из первичных документов и не заменяет их. Для каждого внешнего источника фиксируются применимость и ограничения.

## Требования

- ссылка и дата доступа;
- тип источника;
- изучаемая группа пациентов;
- основные результаты;
- ограничения;
- применимость к пользователю;
- уровень уверенности.
