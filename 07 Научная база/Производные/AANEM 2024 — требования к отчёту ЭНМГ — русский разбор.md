# AANEM 2024 — требования к отчёту ЭНМГ — русский разбор

> [!IMPORTANT]
> Это **этап 2**, а не оригинал и не официальный перевод.
>
> Канонический источник: [[07 Научная база/Источники/AANEM 2024 — требования к отчёту ЭНМГ — карточка источника]].

## 1. Для чего нужен документ

AANEM рассматривает ЭНМГ как клиническое исследование, которое должно оставлять достаточно данных для:

- проверки вывода другим врачом;
- сравнения с предыдущими/последующими исследованиями;
- понимания локализации и тяжести поражения;
- оценки технических ограничений.

Отчёт, содержащий только итоговое заключение без supporting data, недостаточен для независимой проверки.

## 2. Clinical context

Отчёт должен содержать:

- причину направления;
- релевантный анамнез;
- релевантный физикальный/неврологический осмотр;
- клинический вопрос.

Это важно, потому что набор нервов и мышц должен отвечать на конкретный диагностический вопрос.

## 3. NCS — что должно быть записано

### Сенсорные исследования

Для каждого SNAP нужны:

- nerve;
- side;
- stimulation site;
- recording site;
- distance;
- amplitude;
- latency;
- conduction velocity, когда вычисляется;
- reference value или явная маркировка abnormality.

### Моторные исследования

Для каждого CMAP:

- nerve;
- side;
- stimulation sites;
- recording muscle/site;
- расстояние distal stimulation → recording;
- расстояния между stimulation sites;
- CMAP amplitude для каждого site;
- latency;
- conduction velocity;
- конкретный nerve segment, если есть неоднозначность.

Это критично для анализа conduction block и segmental slowing.

## 4. F-wave

Рекомендуется фиксировать:

- нерв;
- site of stimulation;
- recording muscle;
- minimum F-wave latency.

Без этого ретроспективная оценка F-wave criteria CIDP может быть невозможна.

## 5. Reference values

AANEM рекомендует включать laboratory reference values, чтобы внешний эксперт мог независимо проверить данные.

Если референсы не приведены:

- abnormal values должны быть ясно обозначены;
- при запросе должен быть доступен источник норм.

Практическое правило SafeAndrew:

> цифра без метода и референса слабее, чем цифра с лабораторным LLN/ULN.

## 6. Температура

AANEM рекомендует **не просто измерить, а контролировать** температуру в ходе исследования.

Ориентиры текущего документа:

- кисть: **32–36°C**;
- стопа: **30–36°C**.

Холод может удлинять distal sensory/motor latency и снижать скорость проведения.

При сравнении старых исследований неизвестная температура должна отдельно маркироваться как limitation.

## 7. Needle EMG

Для каждой исследованной мышцы нужно описывать:

- insertional activity;
- spontaneous activity;
- positive sharp waves;
- fibrillation potentials;
- fasciculation potentials, если есть;
- voluntary activity;
- recruitment;
- MUP amplitude;
- duration;
- phases/polyphasicity.

Нужно исследовать достаточное число мышц для поставленного differential diagnosis.

## 8. Табличная форма

AANEM предпочитает non-narrative/tabular представление NCS и needle EMG.

Причина:

- проще независимо проверить числа;
- проще увидеть распределение abnormalities;
- проще сравнить myotomes / peripheral nerves;
- проще сопоставить с прошлым исследованием.

## 9. Study limitations

В отчёте нужно фиксировать факторы, способные снизить качество:

- poor tolerance;
- pain;
- limited effort;
- edema;
- толщина подкожных тканей;
- technical limitations;
- contraindications или невозможность выполнить часть тестов.

Отсутствующий параметр и нормальный параметр — не одно и то же.

## 10. Сравнение в динамике

Если доступны предыдущие исследования и они **достаточно сопоставимы**, отчёт должен указать:

- есть ли interval change;
- направление: improved / stable / worsening;
- характер изменения.

Ключевая оговорка AANEM: сравнение уместно только если прошлые данные/отчёты достаточно качественны для сравнения.

## 11. Waveforms

AANEM указывает включение SNAP/CMAP/F-wave/H-reflex waveforms как option.

Для обычного клинического отчёта это необязательно.

Для сложного ретроспективного случая SafeAndrew waveforms особенно ценны, потому что позволяют:

- перепроверить onset markers;
- увидеть shape/duration;
- оценить технический артефакт;
- проверить возможный block/dispersion.

## 12. Что должен запросить SafeAndrew у лаборатории

Минимальный запрос:

1. полный report;
2. numeric NCS tables;
3. laboratory reference values;
4. temperature;
5. stimulation/recording sites;
6. distances;
7. distal/proximal CMAP;
8. SNAP;
9. F-wave minimum latency;
10. needle EMG table по каждой мышце;
11. limitations;
12. waveforms/raw export, если сохранены;
13. comparison with prior study, если лаборатория его делала.

## 13. Оценка старого протокола будущим агентом

Для каждого исследования агент должен присвоить полноту:

- **A:** почти все критические поля доступны + waveforms;
- **B:** числовые таблицы достаточны, но waveforms/часть техданных отсутствует;
- **C:** заключение + неполные цифры;
- **D:** только итоговая фраза/пересказ.

Эта шкала — рабочая схема SafeAndrew, а не классификация AANEM.

## 14. Что этот источник не решает

Он не отвечает:

- есть ли CIDP;
- является ли slowing демиелинизирующим;
- какой protocol нужно выполнить при конкретном phenotype;
- какие reference values корректны для конкретной лаборатории.

Для этого используются EAN/PNS, Uncini, Allen/Broers, Proper Performance и reference-value papers.
