# Cutsforth-Gregory 2018 — ganglionic AChR antibody — русский разбор

> [!IMPORTANT]
Этап 2. Пороговые значения assay-specific.

## 1. Почему titer важен

Один факт seropositivity не одинаково информативен при любом уровне antibody.

В Mayo cohort:

- >0.40 nmol/L имел высокую specificity для severe autonomic failure;
- ≥0.20 nmol/L был более информативен для moderate failure при objective anhidrosis;
- <0.20 nmol/L имел слабую predictive value без clinical/objective autonomic failure.

## 2. Что нельзя делать

Нельзя писать:

`gAChR low-positive → AAG подтверждена`.

## 3. Правильная логика

Оценивать вместе:

- phenotype;
- autonomic reflex screen/CASS;
- orthostatic/sudomotor/cardiovagal deficits;
- titer;
- assay method;
- alternative causes.

## 4. Почему это важно для AGID

Low-titer ganglionic antibody при изолированных GI symptoms может оказаться неспецифичным.

Высокий titer + generalized objective autonomic failure намного сильнее поддерживает AAG-related mechanism.

## 5. Ограничение

Порог Mayo нельзя автоматически переносить на новый cell-based/luciferase/другой assay без cross-validation.
