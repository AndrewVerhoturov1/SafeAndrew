# Cortez 2026 — autonomic testing consensus — русский разбор

> [!IMPORTANT]
Этап 2. Не официальный перевод.

## 1. Зачем нужен objective autonomic lab

Симптомы dysautonomia неспецифичны. Standardized tests позволяют объективно определить:

- есть ли autonomic failure;
- какие domains поражены;
- distribution/severity;
- изменение в динамике.

## 2. Core battery

Consensus включает:

- orthostatic challenge с continuous beat-to-beat BP/HR;
- Valsalva maneuver;
- cardiovagal heart-rate variability/deep breathing;
- sudomotor testing.

## 3. Что каждый domain оценивает

- **adrenergic:** BP responses to Valsalva/orthostasis;
- **cardiovagal:** HR variability/deep breathing/Valsalva;
- **sudomotor:** postganglionic sweat function;
- **orthostatic:** BP/HR response upright.

## 4. CASS

Composite Autonomic Severity Score может количественно отражать adrenergic, cardiovagal и sudomotor failure, если laboratory battery выполнена валидно.

## 5. Quality

Нужны trained personnel, standardized protocol, правильная подготовка пациента и interpretation physician.

## 6. Ограничение для AGID

Systemic autonomic testing может поддержать generalized autonomic neuropathy.

Нормальный autonomic reflex screen **не исключает isolated enteric dysmotility**, поэтому GI motility tests остаются отдельным слоем.

## 7. Правило SafeAndrew

При гипотезе immune dysautonomia агент должен разделять:

`autonomic symptoms`

и

`objectively demonstrated autonomic failure`.
