# mtDNA maintenance defects — neurogastrointestinal phenotype — русский разбор

## 1. MNGIE is a phenotype family, not only TYMP

GeneReviews overview places neurogastrointestinal phenotypes among mtDNA-maintenance disorders caused by:

- TYMP;
- POLG;
- RRM2B.

## 2. Shared pattern

Possible shared manifestations:

- GI dysmotility;
- cachexia;
- peripheral neuropathy;
- ophthalmoplegia/ptosis;
- other mitochondrial organ involvement.

## 3. Key discriminator

Classic TYMP tends to have leukoencephalopathy.

POLG neurogastrointestinal phenotype may **lack** leukoencephalopathy.

Therefore normal/nonclassic brain MRI shifts probability within the mitochondrial branch rather than simply closing it.

## 4. Testing implication

Genetic strategy should cover a broader nuclear mitochondrial set and not rely only on TYMP.

Phenotype may also justify specialist mitochondrial testing beyond ordinary neuropathy panels.
