# Hearn 2024 — serial EDX — русский разбор

> [!IMPORTANT]
> Этап 2. Не официальный перевод.
>
> Канонический источник: [[07 Научная база/Источники/Hearn 2024 — serial EDX — карточка источника]].

## 1. Repeat EDX нужен не по расписанию

Повтор оправдан, когда есть **вопрос**, который невозможно достаточно надёжно закрыть первым time point.

## 2. Четыре показания

### A. Новое/продолжающееся поражение

Есть clinical change → проверить:

- spatial spread;
- ранее normal nerve/muscle;
- evolving pathophysiology.

### B. Неясное progressive disease

Второй time point способен:

- подтвердить progression;
- показать новый phenotype;
- опровергнуть подозрение на progressive process.

### C. Prognosis после static injury

Повтор помогает увидеть:

- reinnervation;
- степень восстановления;
- прогноз function.

### D. Неполный первый test

Если initial EDX ограничен:

- pain/tolerance;
- environmental/technical conditions;
- слишком короткий protocol;
- missing muscles/nerves

повтор нужен, чтобы **добавить недостающие данные**, а не изображать longitudinal progression.

## 3. Что считать сравнимой динамикой

Для longitudinal interpretation желательно:

- same nerve/side;
- same recording muscle/site;
- same segment/distances;
- similar temperature;
- compatible reference framework;
- enough CMAP/SNAP amplitude for reliable marking;
- known technical limitations.

Если это не выполнено, разница должна маркироваться как `technical comparability limited`.

## 4. Почему serial data могут менять diagnosis

Со временем могут появляться:

- spread to new nerves/muscles;
- transition sensory → sensorimotor;
- denervation/reinnervation;
- conduction failure → dispersion/recovery;
- pattern, который не был виден на раннем test.

Поэтому серию нельзя сводить только к одной цифре скорости.

## 5. Sensory neuronopathy

При sensory-neuron loss ранняя/повторная оценка SNAP может быть особенно информативна.

Но при chronic advanced sensory loss отсутствие response уже может давать ceiling/floor effect — измерять дальнейшее ухудшение становится труднее.

## 6. Chronic lesions — ограничения

При longstanding damage:

- electrophysiology может показывать остаточную chronic remodeling, а не ongoing mechanism;
- отсутствие дальнейшего change не означает absence of disease;
- prognostic interpretation слабее.

## 7. Правило SafeAndrew для 2017–2026

Каждая межгодовая разница должна получить один из статусов:

- **comparable biological change likely**;
- **partly comparable**;
- **not directly comparable**;
- **missing data / repeat needed**.

## 8. Особенно для 04 и 05.02.2026

Разница за одни сутки не может автоматически считаться progression.

Сначала проверить:

- recording muscle;
- stimulation sites;
- distances;
- temperature;
- supramaximal stimulation;
- waveform markers;
- equipment/protocol;
- transcription.

Если эти условия различались/неизвестны — два исследования рассматриваются как **discordant technical datasets**, пока expert review не объяснит причину.

## 9. Что должен дать новый baseline, если повтор нужен

Новый expert EDX должен оставить:

- complete numeric tables;
- laboratory references;
- temperature;
- stimulation/recording maps;
- waveforms/raw export if possible;
- enough bilateral/upper-limb sensory data;
- needle EMG distribution;
- explicit comparison with old data.
