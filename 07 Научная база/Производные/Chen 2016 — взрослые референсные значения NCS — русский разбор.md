# Chen 2016 — взрослые референсные значения NCS — русский разбор

> [!IMPORTANT]
> Этап 2. Не официальный перевод.
>
> Канонический источник: [[07 Научная база/Источники/Chen 2016 — взрослые референсные значения NCS — карточка источника]].
>
> **Критическое правило:** значения ниже применимы только при достаточно сходной технике. Они не заменяют reference values конкретной лаборатории.

## 1. Зачем нужен этот документ

Dillingham 2016 объясняет, **как выбирать качественные normative studies**.

Chen 2016 применяет этот фильтр к литературе и публикует практически используемые values для common adult NCS.

## 2. Сколько литературы выдержало фильтр

- >7 500 articles → initial search;
- 401 studies с >100 subjects;
- 83 studies → detailed NDTF review;
- для 10 nerves выбран только один основной high-quality study на нерв;
- superficial fibular sensory — без подходящего primary study.

Это подчёркивает, насколько слабой может быть доказательная база даже для кажущихся 'обычными' лабораторных норм.

## 3. Техника, при которой получены выбранные значения

В selected protocols:

- upper-limb temperature >32°C;
- lower-limb temperature >31°C;
- sensory filters: 20 Hz–2 kHz;
- motor filters: 2–3 Hz–10 kHz;
- distances и electrode positions стандартизированы.

Если старый протокол SafeAndrew выполнен иначе, числа Chen нельзя просто подставлять как точный LLN/ULN.

## 4. Сенсорные reference values — основные примеры

| Нерв / техника | Amplitude LL, µV (onset→peak / peak→peak) | Latency UL, ms (onset / peak) |
|---|---:|---:|
| Superficial radial, antidromic 10 cm | 7 / 11 | 2.2 / 2.8 |
| Median digit 2, wrist 14 cm | 11 / 13 | 3.3 / 4.0 |
| Median digit 2, palm 7 cm | 6 / 8 | 1.6 / 2.3 |
| Ulnar digit 5, 14 cm | 10 / 9 | 3.1 / 4.0 |
| Sural, antidromic 14 cm | 4 / 4 | 3.6 / 4.5 |

Median и ulnar sensory amplitudes имеют age/BMI dependence; для индивидуального применения открывать Table 3 оригинала.

Дополнительно в selected literature lower sensory CV cut-offs были приведены для median, ulnar, radial и sural, но часть этих velocity data происходила из вспомогательного исследования, которое не выполнило все критерии NDTF. Поэтому в SafeAndrew они не используются как равнозначные основным Table 3 values.

## 5. Моторные reference values — базовые all-age values

| Нерв / мышца / distal distance | Distal amplitude LL | CV LL | Distal latency UL |
|---|---:|---:|---:|
| Median → APB, 8 cm | 4.1 mV | 49 m/s | 4.5 ms |
| Ulnar → ADM, 8 cm | 7.9 mV | 52 m/s below elbow; 43 across elbow; 50 above elbow | 3.7 ms |
| Fibular → EDB, 8 cm | 1.3 mV | 38 m/s ankle→below FH | 6.5 ms |
| Tibial → AH, 8 cm | 4.4 mV | 39 m/s | 6.1 ms |

Это all-age summary values; возраст/пол/рост иногда дают другие subgroup thresholds.

## 6. Почему age/height/BMI нельзя игнорировать

### Median motor

- amplitude снижалась с age;
- gender/age имели небольшое, но статистически значимое влияние на velocity и distal latency;
- height не был значимым для median motor в selected study.

### Fibular motor

- taller subjects → lower CV;
- older subjects → lower CV и markedly lower amplitude;
- selected study: amplitude LL 2.6 mV в 19–39 и 1.1 mV в 40–79.

### Tibial motor

- amplitude снижалась с age;
- CV зависела от age + height;
- selected values: amplitude LL 5.8 mV (19–29), 5.3 (30–59), 1.1 (60–79).

Вывод: один all-age LLN иногда скрывает большую физиологическую зависимость от возраста.

## 7. Fibular across-knee values

Для selected fibular protocol:

- across fibular head CV LL: 42 m/s;
- normal maximum velocity drop lower-leg → across-knee: 6 m/s / 12%;
- normal maximum amplitude drop across fibular head: 25%.

Эти values специфичны для описанной техники и не являются universal conduction-block definition.

## 8. Tibial proximal amplitude drop — особо важная ловушка

В selected tibial study normal subjects могли иметь:

- amplitude drop ankle→knee до **10.3 mV**;
- или до **71%**.

Это неожиданно большой proximal drop.

Авторы объясняют его, вероятно, temporal dispersion/phase cancellation при записи abductor hallucis и других tibial-innervated foot muscles.

Практический смысл:

> large tibial proximal amplitude drop сам по себе нельзя механически приравнивать к демиелинизирующему conduction block.

Это согласуется с EAN/PNS 2021, где tibial nerve исключён из motor conduction-block criterion.

## 9. Sural SNAP

В selected healthy cohort:

- bilateral sural responses были recordable у 97%;
- небольшая доля healthy subjects имела unilateral/bilateral absent responses.

Следовательно, отсутствие sural response требует контекста возраста, техники и других sensory nerves.

## 10. Superficial fibular sensory — пробел доказательств

NDTF **не нашла** primary article для superficial fibular sensory, который выполнил бы все quality criteria.

Это важно для агента: отсутствие высококачественной нормы должно быть обозначено как ограничение, а не замаскировано случайной таблицей.

## 11. Правило применения к старым ЭНМГ

Перед использованием таблицы Chen нужно проверить:

1. тот же nerve?
2. та же recording muscle / sensory site?
3. сходная distance?
4. та же antidromic/orthodromic technique?
5. сопоставимые filters?
6. температура?
7. age/height/BMI adjustment?
8. локальная лаборатория имела собственные reference values?

Если ключевые параметры неизвестны, Chen используется только как **ориентир**, а не как основание точного пересчёта diagnosis.

## 12. Сильный вывод для межлабораторного сравнения

Нельзя сравнивать:

`скорость 38 в лаборатории A`

с

`нормой 40 из лаборатории B`

без проверки методики.

Разница в 1–3 m/s может быть меньше методического шума/различий protocol и не должна превращаться в уверенный патологический вывод.

## 13. Что этот документ не охватывает

- F-wave / H-reflex reference values;
- pediatric NCS;
- many uncommon nerves;
- universal modern values для всех приборов/лабораторий;
- специфические CIDP diagnostic thresholds.

Формальные CIDP cut-offs остаются в EAN/PNS 2021.
