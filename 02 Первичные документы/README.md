# Первичные медицинские документы

> [!IMPORTANT]
> Здесь хранятся максимально точные версии выписок, анализов, протоколов и сканов. Интерпретации находятся в других разделах.

## Структура

Документы раскладываются по году исследования или события:

```text
02 Первичные документы/YYYY/YYYY-MM-DD Название документа.md
```

## Правила

- Не менять медицинский смысл оригинала.
- Сохранять дату, учреждение, показатели, единицы и нормы.
- Ошибки распознавания отмечать отдельно.
- Добавлять ссылки на связанные исследования и направления.
