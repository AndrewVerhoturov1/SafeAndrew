## Правила хранения

- Не менять медицинский смысл оригинала.
- Сохранять дату, показатели, единицы и нормы.
- Ошибки и различия расшифровок отмечать явно.
- Исторические назначения не считать автоматически действующей схемой лечения.
- Из других страниц ссылаться на конкретный документ и нужный раздел.
