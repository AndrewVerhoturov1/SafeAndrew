# Гипотезы и открытые вопросы

> [!WARNING]
> Гипотеза не является диагнозом.

## Для каждой гипотезы фиксировать

- формулировку;
- объясняемые факты;
- факты против;
- недостающие данные;
- проверяющие исследования;
- опасность пропуска;
- текущий уровень уверенности;
- дату последнего пересмотра.
