# Симптомы

Каждый значимый симптом получает отдельную страницу с динамикой, тяжестью, возможными причинами и ссылками на исследования.

## Рекомендуемая структура страницы симптома

- описание простыми словами;
- дата начала;
- изменение во времени;
- провоцирующие и облегчающие факторы;
- связанные заболевания и гипотезы;
- связанные исследования;
- признаки, требующие срочной помощи.
