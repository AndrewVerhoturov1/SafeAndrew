# Scientific Library Workflow

## Purpose

This document defines the canonical process for building the SafeAndrew scientific knowledge library.

The library uses three stages:

```
External source
(guideline / textbook / review)
        ↓
Level 1: Sources
        ↓
Level 2: Topics
        ↓
Patient-specific analysis
```

## Level 1 — Source documents

Location: `07 Научная база/Источники/`

Goal: preserve the medical logic of the original source with minimal interpretation.

Rules:
- keep structure, recommendations, criteria, thresholds, exceptions and rationale;
- preserve context;
- record source metadata;
- do not make conclusions about a patient;
- do not select only convenient statements.

A Level 1 document is not a summary. It is a reusable evidence base.

## Level 2 — Topic documents

Location: `07 Научная база/Темы/`

Goal: synthesize multiple Level 1 sources around one clinical question.

Rules:
- combine sources transparently;
- separate established facts, uncertainty and gaps;
- link every important claim back to Level 1;
- do not replace source text with model memory.

## Source priority

1. Clinical guidelines and consensus documents.
2. Evidence reviews.
3. Major textbooks and handbook chapters.
4. Systematic and major reviews.
5. Key original studies.

## Agent workflow

1. Define the clinical question.
2. Check existing sources and topics.
3. Validate source identity, version and status.
4. Create or update Level 1.
5. Create or update Level 2 if synthesis is needed.
6. Verify backlinks and anchors.
7. Record limitations.

## Separation rule

Scientific sources explain medicine. They do not replace primary patient records. Patient conclusions belong only to medical analysis documents.
